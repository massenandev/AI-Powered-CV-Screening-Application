# Demo checklist

1. Copy `.env.example`, set the Gemini key, and start Docker Compose.
2. Run indexing twice; show that the second run skips all unchanged PDFs.
3. Open the UI and ask a factual skills question; expand its source excerpt.
4. Ask for a candidate comparison and explain broader retrieval.
5. Ask about an absent fact and demonstrate grounded uncertainty.
6. Show the domain ports, application service, thin route, migration, and focused tests.
7. Walk through the architecture diagram, decisions, limitations, and measured scaling path.
8. Reinforce that this supports—not automates—employment decisions.
